Key DFS Use Cases in Interviews
Path existence A to B   -> Traverse + visited set
Cycle detection         -> Track recursion stack (back edge)
Connected components    -> DFS from each unvisited node

Grid DFS - Very Common
fun dfs(grid: Array<CharArray>, i: Int, j: Int) {
if (i < 0 || i >= grid.size || j < 0 || j >= grid[0].size) return
if (grid[i][j] != '1') return
grid[i][j] = '0'  // mark visited by mutating
dfs(grid, i + 1, j)
dfs(grid, i - 1, j)
dfs(grid, i, j + 1)
dfs(grid, i, j - 1)
}
Complexity
       Tree        Graph
Time    -> O(N)     -> O(V + E)
Space   -> O(H)     -> O(V) visited set
