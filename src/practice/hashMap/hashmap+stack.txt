PATTERN — FREQUENCY COUNT
--------------------------
Most common use: find duplicates, top K, first unique.
Brute force thought: nested loop to compare every element.
HashMap insight: one pass to count, one pass to query.

val freq = HashMap<Int, Int>()
for (n in nums) freq[n] = (freq[n] ?: 0) + 1

PROBLEM 1 — SUBARRAY SUM EQUALS K
================================================================

Count subarrays whose sum equals k.

Input:  [1, 1, 1], k = 2
Output: 2

Input:  [1, 2, 3], k = 3
Output: 2

--- BRUTE FORCE O(n²) ---

fun subarraySumBrute(nums: IntArray, k: Int): Int {
    var count = 0
    for (i in nums.indices) {
        var sum = 0
        for (j in i until nums.size) {
            sum += nums[j]
            if (sum == k) count++
        }
    }
    return count
}

--- OPTIMAL O(n) prefix sum + HashMap ---

fun subarraySum(nums: IntArray, k: Int): Int {
    val prefixCount = HashMap<Int, Int>()
    prefixCount[0] = 1  // empty subarray
    var sum = 0
    var count = 0

    for (n in nums) {
        sum += n
        count += prefixCount.getOrDefault(sum - k, 0)
        prefixCount[sum] = (prefixCount[sum] ?: 0) + 1
    }
    return count
}

Key insight:
If prefixSum[j] - prefixSum[i] = k, then subarray [i+1..j]
sums to k. For every index, check if (currentSum - k) was
seen before as a prefix sum.

Complexity: Time O(n) | Space O(n)

PROBLEM 2 — LRU CACHE
================================================================

Design a data structure that holds at most capacity items.
On get/put, most recently used item stays.
Least recently used is evicted.

LRUCache(2)
put(1, 1)  -> cache: {1=1}
put(2, 2)  -> cache: {1=1, 2=2}
get(1)     -> returns 1, cache: {2=2, 1=1}
put(3, 3)  -> evicts 2, cache: {1=1, 3=3}
get(2)     -> returns -1

--- BRUTE FORCE ---
List + scan -> O(n) per operation.

--- OPTIMAL LinkedHashMap O(1) ---

class LRUCache(private val capacity: Int) {

    private val cache = object : LinkedHashMap<Int, Int>(
        capacity, 0.75f, true
    ) {
        override fun removeEldestEntry(
            eldest: Map.Entry<Int, Int>
        ) = size > capacity
    }

    fun get(key: Int): Int = cache.getOrDefault(key, -1)

    fun put(key: Int, value: Int) {
        cache[key] = value
    }
}

Key insight:
LinkedHashMap with accessOrder=true keeps most recently
accessed at tail, least recently at head.
removeEldestEntry auto-evicts when over capacity.

Complexity: Time O(1) | Space O(capacity)

PATTERN — MONOTONIC STACK
--------------------------
Use when: "next greater element", "previous smaller",
          "daily temperatures", "largest rectangle"

Core idea: maintain a stack always increasing or decreasing.
When current element breaks the order, pop and process.

val stack = ArrayDeque<Int>()  // stores indices
for (i in nums.indices) {
    while (stack.isNotEmpty() && nums[i] > nums[stack.last()]) {
        val idx = stack.removeLast()
        // process: next greater for idx is nums[i]
    }
    stack.addLast(i)
}

PROBLEM 3 — DAILY TEMPERATURES
================================================================

Given temperatures, find how many days until a warmer
temperature. If none, put 0.

Input:  [73,74,75,71,69,72,76,73]
Output: [1, 1, 4, 2, 1, 1, 0, 0]

--- BRUTE FORCE O(n²) ---

fun dailyTempsBrute(temps: IntArray): IntArray {
    val result = IntArray(temps.size)
    for (i in temps.indices) {
        for (j in i + 1 until temps.size) {
            if (temps[j] > temps[i]) {
                result[i] = j - i
                break
            }
        }
    }
    return result
}

--- OPTIMAL O(n) monotonic stack ---

fun dailyTemperatures(temps: IntArray): IntArray {
    val result = IntArray(temps.size)
    val stack = ArrayDeque<Int>()  // stores indices

    for (i in temps.indices) {
        while (stack.isNotEmpty() && temps[i] > temps[stack.last()]) {
            val idx = stack.removeLast()
            result[idx] = i - idx  // days to wait
        }
        stack.addLast(i)
    }
    return result
}

Key insight:
Stack holds indices of days waiting for a warmer day.
When a warmer day arrives, pop all cooler days and record
the wait. Remaining in stack get 0 (default).

Complexity: Time O(n) | Space O(n)

PROBLEM 4 — VALID PARENTHESES
================================================================

Check if brackets are valid and correctly ordered.

Input:  "()[]{}"  -> true
Input:  "([)]"    -> false
Input:  "{[]}"    -> true

--- OPTIMAL O(n) stack ---

fun isValid(s: String): Boolean {
    val stack = ArrayDeque<Char>()
    val map = mapOf(')' to '(', ']' to '[', '}' to '{')

    for (c in s) {
        if (c in map.values) {
            stack.addLast(c)
        } else {
            if (stack.isEmpty() || stack.last() != map[c])
                return false
            stack.removeLast()
        }
    }
    return stack.isEmpty()
}

Key insight:
Push opening brackets. When closing bracket arrives,
check if it matches top of stack.
If not -> invalid. Stack empty at end -> valid.

Complexity: Time O(n) | Space O(n)
